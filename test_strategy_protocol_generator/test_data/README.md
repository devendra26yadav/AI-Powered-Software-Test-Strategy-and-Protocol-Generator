# Test Data for the Test Strategy Protocol Generator

Use these sample files to validate the document upload flow with a general software project.

Upload all of the files together and confirm the checkbox before generating a strategy.

## Included files
- `product_requirements.md` — functional and non-functional requirements for an inventory web application
- `architecture_overview.md` — system architecture and component responsibilities
- `user_stories.txt` — user story examples
- `test_plan.yaml` — QA and test plan configuration
- `risk_register.csv` — risk summary data

## Suggested test topic
Testing a SaaS inventory management web application
